# Studio — استوديو تصميم أونلاين

ويب أب للتصميم بيشتغل بالكامل في المتصفح (اسم المنتج لسه مؤقت، وبيتغيّر من `src/config.ts`).

## الأدوات

| الأداة | بتعمل إيه |
|---|---|
| **محرر التصميم** | مقاسات جاهزة وقوالب، نصوص بخطوط عربية وإنجليزية، صور، أشكال، ستيكرز، طبقات، تجميع، قفل وإخفاء، أدلة محاذاة، تراجع وإعادة، كذا صفحة، خلفيات (لون، تدرّج، صورة)، وتحميل PNG / JPG / PDF / ملف مشروع |
| **فتح ملفات PSD** | كل طبقة بتتحول لعنصر تقدر تعدّله، وطبقات النص بتتحول لنص قابل للتعديل (والصورة الأصلية بتفضل طبقة مخفية جنبها) |
| **صانع السيرة الذاتية** | 4 قوالب، عربي أو إنجليزي، لون أساسي وخط، صورة شخصية، ومعاينة فورية. التحميل PDF بنص حقيقي ينفع يتحدد ويتنسخ (مناسب لأنظمة فرز السير الذاتية ATS) |
| **إزالة الخلفية** | ذكاء اصطناعي جوه المتصفح. نموذج سريع للأشخاص (MODNet, Apache-2.0) ونموذج دقيق لأي حاجة (BiRefNet-lite, MIT) |
| **محرر PDF** | نص، صور، توقيع بخط اليد، مسح أبيض، تظليل، مربعات، رسم حر، تدوير وحذف صفحات. نص الملف الأصلي بيفضل زي ما هو |

**الخصوصية:** مفيش سيرفر خالص. التصميمات بتتحفظ في متصفح المستخدم (IndexedDB)، والملفات عمرها ما بتترفع.

## التشغيل على جهازك

```bash
npm install
```

```bash
npm run dev
```

## الرفع على Hostinger (استضافة عادية)

1. ابني المشروع:
   ```bash
   npm run build
   ```
2. هيطلع فولدر اسمه `dist/`. ارفع **كل اللي جواه** (مش الفولدر نفسه) على `public_html` من File Manager في hPanel، أو بـ FTP.
3. خلاص كده. الموقع بيستخدم روابط فيها `#` (زي `/#/editor/...`)، فمش محتاج أي إعدادات على السيرفر. ملف `.htaccess` اللي جوه `dist` بيظبط الكاش والضغط بس.

> ملف الذكاء الاصطناعي (`ort-wasm-*.wasm`، حوالي 27 ميجا) بيتحمّل بس لما حد يستخدم إزالة الخلفية. نماذج الذكاء الاصطناعي نفسها بتيجي من Hugging Face CDN أول مرة، وبعدها المتصفح بيحتفظ بيها.

## التقنيات

React 19 + TypeScript + Vite + Tailwind CSS · Fabric.js (الرسم والتعديل) · ag-psd (ملفات PSD) · pdf.js + pdf-lib (ملفات PDF) · transformers.js (إزالة الخلفية) · idb-keyval (الحفظ في المتصفح)

## هيكل الكود

```
src/
  config.ts            اسم المنتج
  i18n/                الترجمة (عربي/إنجليزي) واتجاه الصفحة
  lib/                 الحفظ، الخطوط، القوالب، PSD، إزالة الخلفية، التحميل
  pages/Home.tsx       الصفحة الرئيسية
  pages/NewDesign.tsx  اختيار المقاس أو القالب
  pages/editor/        المحرر (controller.ts فيه كل منطق الكانفاس)
  pages/cv/            صانع السيرة الذاتية
  pages/pdf/           محرر PDF
  pages/RemoveBg.tsx   إزالة الخلفية
```
